gscript

Ferramenta pessoal para manter projetos do Google Apps Script

O gscript é um conjunto de scripts que roda no computador do próprio titular e cuida dos projetos do Google Apps Script dele:

  • sobe alterações de código para os projetos;
  • cria versões novas e atualiza a implantação já existente, mantendo o mesmo endereço do app da web;
  • faz cópia de segurança diária do código, das versões, das implantações, do histórico de execuções e das métricas de uso.

Como funciona

O titular autoriza o gscript uma única vez, com a própria conta Google (OAuth). A partir daí, os scripts conversam direto com as APIs do Google (Apps Script API e metadados do Google Drive), sem servidor intermediário.

O gscript é de uso pessoal: tem um único usuário, que é também o desenvolvedor, e não é oferecido a terceiros.
